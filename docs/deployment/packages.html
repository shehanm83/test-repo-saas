Monorepo Package Map

pnpm workspace with 2 apps and 10 packages. Each package has a single well-defined responsibility and communicates through explicit TypeScript interfaces. No package imports directly from another app.

Package Details

Each package has a single responsibility and exports a clean TypeScript interface
🌐
@layertone/shared
packages/shared/
Foundation package. Defines the Config type (all environment configuration), the Adapters interface (AI, queue, storage, telemetry), and shared types used across the monorepo. Zero internal dependencies.
Web Lambda Worker Lambda
Key exports
Config, Adapters, AIImageRequest
NormalizedCommercialGenerationInput
buildQuickCreatePrompt() — prompt templates
🐘
@layertone/db
packages/db/
Drizzle ORM schema definitions for all tables (users, workspaces, brands, generations, generation_variants, templates, moods, ledger, caption_jobs, etc.), migration runner, and typed query helpers like getGenerationFull().
Web Lambda Worker Lambda
Key exports
createDb(url, role) — creates typed db client
Table schemas: generations, brands, moods, ...
getGenerationFull(), updateCaption()
🤖
@layertone/gateway
packages/gateway/
AI provider gateway. Implements the ImageProvider and TextProvider interfaces for OpenAI (DALL-E 3, GPT-4o), Replicate, Recraft, AWS Bedrock (SD3.5), and a Mock provider for testing. Routing logic selects provider by model code.
Worker Lambda only
ImageProvider interface + implementations
TextProvider interface + implementations
MockImageProvider (dev/test)
routeToProvider(modelCode)
✨
@layertone/renderer
packages/renderer/
Template rendering engine. Takes a JSX template source, a background image, brand tokens (palette, fonts, logo), mood data, and overlay slots; returns a PNG buffer. Uses Satori for SVG→PNG rendering, with Puppeteer/Chromium fallback for complex templates.
Worker Lambda only
render(RenderInput, options) → PNG bytes
Uses @sparticuz/chromium for Lambda-compatible Chromium
💳
@layertone/billing
packages/billing/
Stripe integration for subscriptions and top-ups. The Ledger class handles the credit lifecycle: reserve credits when a generation is created, commit on success, release on failure. All operations are idempotent via idempotencyKey.
Web Lambda Worker Lambda
Ledger.reserve(), .commit(), .release()
Stripe subscription + top-up handlers
🔐
@layertone/auth
packages/auth/
Clerk authentication adapter. Handles JWT verification for API routes, Clerk webhook processing (user.created, user.deleted), and maps Clerk user IDs to workspace IDs in the database.
Web Lambda only
verifyJwt(token) — validates Clerk session tokens
handleClerkWebhook(event)
📬
@layertone/queue
packages/queue/
Queue abstraction with three implementations: SqsQueueAdapter (AWS SQS / ElasticMQ), and InlineQueueAdapter (in-process for testing). The interface is trivial to extend — adding a QStash adapter for Vercel migration takes ~1–2 days.
Web Lambda Worker Lambda
QueueAdapter interface
SqsQueueAdapter, InlineQueueAdapter
🗄️
@layertone/storage
packages/storage/
Storage abstraction with an S3-compatible implementation that works with both AWS S3 and MinIO. The keys module provides canonical S3 key patterns for all object types (brand assets, generation backgrounds, variant outputs, inspiration uploads).
Web Lambda Worker Lambda
StorageAdapter interface
S3StorageAdapter (AWS S3 + MinIO)
keys.* — S3 key helpers
🔴
@layertone/observability
packages/observability/
Sentry error monitoring and CloudWatch metrics. Exports a TelemetryAdapter that wraps Sentry's captureException() and CloudWatch's PutMetricData in a single interface. Instruments Lambda execution with tracing spans.
Web Lambda Worker Lambda
TelemetryAdapter.captureException()
TelemetryAdapter.metric(name, value, tags)
tagSpan() — adds attributes to current trace span
📡
@layertone/api
packages/api/
Shared API handler logic called by both the web Next.js API routes and the worker. Encapsulates generation creation, brand CRUD, template lookups, and other domain operations that need to be accessible from both runtimes.
Web Lambda Worker Lambda

Workspace Structure

pnpm workspace layout with pnpm-workspace.yaml

├── apps/
│ ├── web/ ← Next.js 16 · Web Lambda · :3000 local
│ └── worker/ ← SQS consumer · Worker Lambda

│ ├── db/ ← Drizzle ORM · migrations

│ └── renderer/ ← Satori + Puppeteer template engine (worker only)

├── e2e/ ← Playwright end-to-end tests
